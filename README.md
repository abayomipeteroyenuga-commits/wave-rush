# Ethan Wave Rush

Water skating arcade game with realistic rider, four-direction movement, AI races, trick competitions, missions, quests, shop, upgrades and emotes.

## Upload to GitHub
1. Extract this ZIP.
2. Create a GitHub repository.
3. Upload all extracted files directly into the repository root.

## Vercel
Import the GitHub repository. Select Other as the framework. Leave the build command empty and set the output directory to `.` (the repository root). No install command or environment variables are required.

## GitHub Pages
In repository Settings > Pages, choose Deploy from a branch, main, / (root).

## Run locally
Open index.html in a browser, or serve this folder using any static web server.

## Controls
Arrow keys or W A S D: move up/down/sideways. Space: jump. Shift: boost. T: airborne trick. E: emote. P: pause. Touch controls are provided.

Coins, missions, upgrades and records are saved in the current browser. Opponents are AI; live online multiplayer is not included. Sound is enabled using the Sound button.
